# Assets folder

Drop your real files here — the site already points to these paths via
`src/data/portfolioData.js`.

| File you need                | Put it at                              |
|-------------------------------|-----------------------------------------|
| Profile photo                 | `public/assets/profile.jpg`             |
| Resume PDF                    | `public/assets/resume.pdf`              |
| Open Graph preview image      | `public/assets/og-image.png`            |
| Project screenshots           | `public/assets/projects/<name>.png`     |
| Certificate images            | `public/assets/certificates/<name>.png` |
| Achievement images            | `public/assets/achievements/<name>.png` |

Nothing here is required for the site to run — every image has a graceful
fallback — but adding real files will make the portfolio look complete.
